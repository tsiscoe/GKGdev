### 2. Verified Active Design Constraints (Core UI DNA)

To ensure operational continuity in subsequent execution blocks, the design system mandates absolute adherence to the following parameters:

* **Typography:** Primary font family must be **Roboto**. Text sizing maps to an 11pt information density layout (`text-xs` to `text-sm` variants with highly compact vertical leading).
* **Geometry:** Primary containers, data modules, inner panels, and structural blocks must use an explicit **24px border radius**.
* **Layering & Depth:** Surfaces utilize a glassmorphic standard consisting of a translucent background (`bg-white/75` or `bg-slate-900/75`), a high-performance hardware-accelerated blur (`backdrop-blur-md`), and a micro-border (`border-slate-200/50` or `border-white/10`).
* **Visual Prohibitions:** **Strict Vector Ban.** No SVG tags, inline paths, or external vector packages may be generated within the markup. No Mermaid.js dependencies or markdown flowchart interpreters are permitted. Breakouts and connectivity pipelines must be achieved exclusively through semantic HTML containers, grid structures, flexboxes, and CSS pseudo-elements/dashed utilities.
* **Chart.js Telemetry Rigor:**
* **Label Length Validation:** All active chart dataset labels must pass through a line-wrapping matrix. Any string parameter exceeding **16 characters** must be split into a multi-line array block to prevent axis clipping.
* **Tooltip Isolation:** Charts must explicit state multi-line tooltip configurations via the `callbacks: { label: ... }` parameters to ensure text payloads output accurately on hover without clipping against container borders.

### 4. Operational Debugging Triggers (Known Issues & Risk Mitigation)

When testing or initialising these SPAs with complex multimodal inputs, look out for the following systematic failures:

1. **SVG Leaks:** Downstream models occasionally inject SVG elements inside the process nodes out of habit. Ensure all connectivity arrows are managed strictly via layout boxes or text symbols (`->`).
2. **Font Scaling Divergence:** Models sometimes drop the explicit font family declaration from Chart.js option defaults. Ensure `Chart.defaults.font.family` is globally instantiated.
3. **Corner Radius Regressions:** Watch for occurrences of `rounded-md` or `rounded-lg` on child containers. All primary surfaces must retain `rounded-24` or utility equivalent geometry definitions.
4. **Label Overlaps:** In instances where label strings are multi-word phrases, verify that the custom line-wrapping array processor is cleanly managing word boundaries before passing variables to the canvas instantiation loop.
