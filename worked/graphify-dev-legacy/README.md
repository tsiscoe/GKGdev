# Graphify Dev Legacy Content

This worked example preserves legacy content from `tsiscoe/Graphify-Dev` after replacing the local checkout with a real fork of `safishamsi/graphify`.

The migrated material is kept under `raw/` so it can be extracted with Graphify without mixing legacy scaffolding into the upstream project source tree.

Included:

- `knowledge_graph/` intake and analysis notes
- `data/` placeholder folders
- `governance/` notes
- `toolkit/` notes
- legacy `docs/README.md` as `raw/legacy-docs/README.md`

Intentionally excluded:

- legacy `package.json` and `package-lock.json`
- generated `.graphify/` SQLite/JSON/report artifacts
- legacy root `README.md`, which duplicated the project title rather than content
